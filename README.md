# IP Geolocate

A mobile-friendly web app for looking up the location of any IP address. No installs, no server — works from any browser.

**Live site:** [fk3l3.github.io/ip-geolocate-tool](https://fk3l3.github.io/ip-geolocate-tool/)

## Features

- Enter one or more IPs (one per line) and tap **Locate IPs**
- Tap **My IP** to auto-detect and look up your current public IP
- Results appear as cards showing country flag, city, region, ISP, and ASN
- Interactive map pins all located IPs with popups
- Dark / light theme toggle, saved between sessions
- Works on desktop and mobile

## Usage

Open the link above in any browser and start looking up IPs. No account, no setup.

To look up multiple IPs at once, paste them one per line into the text box.
